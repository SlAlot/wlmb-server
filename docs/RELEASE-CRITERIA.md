# 1.0 首个正式版本检查清单

版本：1.0.0，作者SlAlot；仅插件按非商业使用及来源声明许可公开。正式版本号不代表所有模组／固件均经过硬件认证。

## 本轮发布要求

- 当前发布文件不含小程序／商业Web／授权服务器、签名秘密或授权WASM。
- Rust后端与独立前端分离；旧移植前端和无用阶段文档从当前目录移除，保留可恢复副本。
- 业务注释改为中文；第三方许可原文、工具生成标记按其要求保留。
- 测试、完整Clippy、格式、接口契约、安装包ABI／版本／HTTPS／清单核对通过后，才附正式产物。
- 检查手机／PC尺寸约束、两主题、弹窗、控件、长文本、可访问状态和减少动态效果。
- 性能分开记录插件主进程、整机与临时外部子进程范围；不能用Rust语言或单次RSS证明更低占用。
- 公开范围仅为已审查插件，不包含闭源客户端；扫描当前文件和全部可达提交。

## 仍需用户／硬件验收

真实微信与浏览器最终视觉、各模组固件短信事件／收发／转发、锁定保存后的实际RF／重启状态、WiFi重载、设备限制与加速兼容，以及多设备／长时间负载。

当前型号识别映射不等于全部协议／硬件通过；缺失能力隐藏或解释，不因为正式版标识变成“已支持”。供网路由器未执行锁频、短信发送／删除或WiFi更改。
