# 1.0.0 功能与适配复查

适用版本：首个公开版本1.0.0，仅OpenWrt插件。精确提交与制品摘要以Release为准。下列数字描述代码入口，不代替硬件认证。

## 对照范围与结论

参考基线为FUjr/QModem的`c49654efc870f53712ee8e25bf181722eb1466d9`，配置事实与协议文件哈希记录在仓库中；身份及平台映射无缺项。见[上游仓库](https://github.com/FUjr/QModem)与[来源说明](QMODEM.md)。

目录为91个唯一型号、131份USB／PCIe配置。共享与独立模式共用解析／锁定协议，但端点占用、固件能力与共享服务接口会进一步限制可用功能。不能把91个身份映射说成91个型号的全部功能已经通过。

## 明确缺项型号

锁频未实现10个：s10、mt5710-cn、mh5000-31、mh5000-82、mh5000-82m、rg801、srm815、srm825、srm825n、srm821。

锁小区未实现28个：上述10个，以及em9190、em9291、mc7354、mc7355、fn990a40、simcom-a8200-serias、a8200c-m2、a7605c、t77w968、t99w175、t99w373、t99w368、t99w640、mv32-w-a、mv32-w-b、n510m、me3630-w、air724ug。

邻区当前未开放27个：mh5000-82、mh5000-82m、rg801、srm815、srm825、srm825n、srm821、mc7354、mc7355、fn990a40、simcom-a8200-serias、a8200c-m2、a7605c、simcom-d8200g、simcom-sim8200ea-m2、simcom-sim8202g-m2、simcom-sim8380g-m2、t77w968、t99w175、t99w373、t99w368、t99w640、mv32-w-a、mv32-w-b、n510m、me3630-w、gm800。

温度协议覆盖89个，n510m、air724ug没有已核验路径，不编造指令。按平台解析摄氏度、十分之一度或毫度，拒绝截断、哨兵值和混杂传感器；模组核心优先，不把射频功放／板温冒充核心温度。可选查询60秒刷新、有效期90秒，有有效结果不追加备用查询，MC7354／MC7355复用GSTATUS。签约速率不是测速，QCI不是CQI，不借用其他上下文、载波或型号补值。

Sierra的4个模板锁频协议读取实际频段与掩码，保留GW、其他制式与SA／NSA，确认后写入并回读；不兼容格式拒绝写入，不自动飞行或重启。上游禁用项、开放路径与主动扫描区别见[协议对照](UPSTREAM-PARITY.md)。

## 短信的两种模式

- 独立模式：自有Rust端点，空闲占用核验；支持的通知优先按索引增量收取、PDU分段组装，默认10秒兜底。固件不兼容或事件不足时回到安全快照，不声称所有模组均有URC。
- 共享模式：先核验QModem短信服务。符合已审查的数据库接口时用其消息／事件；否则走共享AT。收发／删除能力取决于数据库管理接口、事务租约，或已核验的QModem队列与原始发送接口，不自行抢串口。
- 已读由插件独立维护；发送／删除需确认，结果不明不重放。PushPlus只转发新短信，有界批量合并；事件优先，忙碌退避，服务端限流与网络耗时不算固定送达保证。
- 两项关闭不运行后台收取；关闭转发不擅自关闭用户独立收取。短信送达须对应模组、固件、共享服务与推送目标验收。

## 小程序与系统功能

契约定义24项入口，已接OpenWrt客户端预设与Rust路由核对；状态、锁定回执、短信与转发设置、WiFi／设备／流量控制走统一鉴权和能力门禁，写入超时不重发。小程序源码与商业授权不发布。

WiFi制式／加密／信道／带宽和双频合一、在线设备／上网限制、流量账本／实时速率／限额、系统温度／CPU／内存已有代码与离线回归。普通LAN AP之外的MLO、复杂多AP／STA和加速绕过不保证；有线逐设备速率必须有可核验计数，没有则留空，不按整接口速率分摊。

所有型号的`hardwareAccepted`为false，表示没有逐型号／固件完整验收记录。`protocolComplete=false`、`hardwareComplete=false`。门禁报告中568个“总线配置×功能”项包含未实现与运行时条件，不是568个型号；具体范围以逐型号、逐功能JSON为准。

## 验证边界

解析、异常回复和双通道测试使用模拟端点；没有对应型号实机时不宣称全固件通过。Release记录真实构建提交及检查结果，功能列表见[首版记录](../CHANGELOG.md)。

1.0.0按能力开放并明确兼容边界，不能宣传“QModem全模组全部功能完整适配”。上述协议缺项及真实短信／锁定／WiFi／长期负载仍需后续验证；版本号不代替协议或硬件证据。

CI的`wlmb-release-readiness`附件同时提供门禁报告及`wlmb-compatibility.json`，后者列出全部91个型号和每个功能状态；可用`tools/compatibility-report.cjs`从`--catalog`结果重新生成。
