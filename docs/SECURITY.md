# 发布范围与安全边界

## 当前源码

发布内容仅为OpenWrt插件：Rust后端、自有WebUI、安装配置、离线测试和文档。商业小程序、Web客户端、授权服务、签名私钥与授权WASM不在导出范围。APK验证公钥是公开资料，不包含私钥。项目许可仅授予非商业使用及来源声明条件下的权利，不替代第三方原有许可。

插件的 `backend/src/security.rs` 是局域网登录／会话／一次性确认，不是商业授权。删除这些保护会让局域网设备可直接改模组与WiFi，因此必须保留。

原始小程序图标字体不发布；仅使用有许可的Framework7图标轮廓与作者自绘SVG路径。许可原文在[图标来源](ICON-SOURCES.md)和随包安装的ui-notices.html中。

## 接口保护

1.0.3起正式APK由专用发布密钥签名，首次信任公钥必须由用户核对指纹后执行；不修改系统全局验签策略，不由安装包自动导入信任。普通分支和PR构建不使用正式私钥。验签只能证明包由受信任密钥签署且未损坏，不代表无漏洞或全模组硬件认证。签名密钥泄露时应停止发布、公告撤销旧公钥及新公钥指纹，不静默替换用户信任。

根账户登录通过系统ubus核验，不把系统root会话交给客户端。插件令牌使用安全随机数，按IP绑定，存摘要、有过期时间与容量上限；失败登录受限流约束。

写操作先prepare、再execute，绑定会话、模组、内容和身份，确认仅用一次。断线、超时和未知结果不自动重发。任意shell、UCI路径和串口路径不通过LAN接口开放。

诊断只包含脱敏错误和能力，不包含号码、短信、Token、密码或原始授权凭据。私有状态目录有权限检查和有界持久化。

## 使用风险与公开前检查

一键安装器固定到对应版本、包摘要和公钥指纹；首次执行脚本依赖对官方GitHub来源及HTTPS的信任，不把下载脚本自身的信任包装成由其内部摘要证明。仅在用户确认或显式使用--yes后持久导入公钥、安装软件；--check不导入系统信任。预检失败回收本次新公钥，安装开始后不自动强制回滚用户数据。相同文件名的不同公钥会被拒绝，不替换系统原有钥匙，不关闭签名检查；IPK不宣称有APK逐包签名保证。

LAN HTTP未加密，只可用于可信局域网；不要把1117映射到公网。锁频、WiFi和限制上网可能影响连接，应先准备恢复手段。

公开内容限定为本插件及其构建、测试和文档。源码与完整可达提交需通过边界扫描；构建缓存、原始设备观测、备份、闭源客户端及个人配置不得提交。

审计工具区分当前文件与历史对象，不把静态扫描当成完整渗透测试或无漏洞保证。请勿在Issue中粘贴密码、Token、号码、短信正文或未脱敏日志。
