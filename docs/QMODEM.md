# QModem 参考来源与独立实现

网络面板根据qmodem为参考开发接入，Rust代码由本项目独立实现；不包含QModem商业受限实现。

## 参考范围

- 型号／厂商／平台／USB与PCIe配置事实及支持频段资料。
- 各平台公开AT命令名称、参数格式、回复字段与能力差异。
- at-daemon的公开调用格式，以及经审查的队列／事务契约。
- rpcd `qmodem` 对象的 `send_at` 传输契约，以及 `cell_info`、`network_info`、`base_info`、`get_current_band`、`get_neighborcell` 信息查询格式。
- qmodem.sms第三版的数据库、managed发送、删除和URC事件接口。

锁定、解析、缓存、身份复核、权限、去重、持久账本、HTTP/RPC和WebUI为自有实现。不复制示例伪数据、硬编码邻区或第三方商业授权代码。

## 固定参考与更新

上游：https://github.com/FUjr/QModem 。已审查基线提交 `c49654efc870f53712ee8e25bf181722eb1466d9`。

`qmodem-upstream.json`保存型号／平台事实和源文件哈希；`model-bands.json`保存频段事实，不等于写协议已支持。通过 `tools/qmodem-audit.cjs` 和 `.github/workflows/qmodem-audit.yml` 检测上游变化，变化先进入报告，由维护者审查后再更新基线；不能自动复制或执行新命令。

短信v3接口另于2026-10-14核对公开main的对象、方法、模式和字段，版本及签名运行时必须匹配；并非假定所有已安装QModem均为v3。

载波与邻区接口另于2026-10-18核对公开提交 `73d18392db358fb4a0da6ace1af0d07978bae324` 的移远实现，以及上述基线的厂商脚本、rpcd 与 LuCI 调用。此项接口审查不替代型号资料基线，也不表示所有固件已经真机验收。

## 共享与独立

检测到QModem时核验共享服务，不接管它的拨号或串口；未知ABI和占用拒绝不安全操作。没有QModem时使用自有通道，仍必须核验接口空闲。两者共用协议解析和能力门禁。

不能用 `at-daemon list` 为空判断 QModem 无法采集。部分固件通过自己的 rpcd 查询信息，串口未常驻在 at-daemon 中。插件检查公开方法签名：共享 AT 已就绪时保持原路径；未就绪时，已适配的被动邻区协议优先借用 QModem 的 `send_at` 传输，由插件自行采集和解析。不具备相应签名或协议时，支持 `cell_info(config_section)` 的设备仍可读取原生信息；不根据版本号硬编码切换。

原生路径归一化 4G／5G SA／NSA 的信号、频段、小区与明确关联的载波信息；可选读取签约速率与模组温度。CQI 不冒充 QCI，缺失字段不补造，WiFi和网口速率仍来自系统接口。后台至少间隔十秒完成一次原生采集，温度查询缓存一分钟，所有客户端共用快照。采用 QModem 信息快照时，回复可能来自其缓存，标记 `providerCached` 和 `sourceCacheAgeUnknown`；`observedAtMs` 是插件查询的时间，不承诺模组的原始测量时间。该采集间隔与短信事件／兜底检查无关。

原生信息可读不等于锁频、主动邻区扫描、短信收发或删除可用。这些操作继续走已有独立能力检查，不通过任意 `send_at` 绕过安全门禁。模组实例或采集通道、厂商或查询能力变化后丢弃旧结果；可选信息失败不清空已有主信号。

## 原生载波与邻区

### 借用共享 AT，自行解析

检测到 `send_at(config_section, params)` 且型号／平台具备已审查的被动邻区协议时，使用 `modems[].infoInventorySource=qmodem.send_at`。QModem 只执行固定查询，插件复用独立模式的型号命令、回复解析、单位换算及缓存，不调用其 `get_neighborcell` 或 `get_current_band` 来整理本轮邻区／载波。

接口参数按 ubus 实际签名编码：字符串型使用 JSON 字符串，表型使用对象。不能只看上游源码中 `params` 的文字标签来猜实际类型。配置节、已配置 AT 端口和 `use_ubus` 绑定到一次采集，发送前后重新核对；不覆盖 QModem 的工具选择，不打开、关闭或认领其串口。请求仅允许编译内的被动信号／载波／邻区查询，底层 ubus 客户端也执行参数白名单检查，不开放通用 AT 代理。

完成性核验区分实际工具：`tom_modem` 保留模组终止行，`sms_tool_q` 的 AT 子命令默认去掉成功终止行。后者仅在工具配置仍匹配、QModem 返回成功状态、命令和端口匹配、且存在对应查询标签时归一化供解析，标记 `completionSource=qmodem-helper-status`；空串不能补成成功，失败、混帧及不可识别布局不解释为“没有邻区”。该归一化不用于任何写入或锁定确认。

先发布服务测量，邻区和载波经过读取前后的驻留身份校验后再发布，原始查询时间戳不前移。单轮最多三种查询，另最多复核三种包含服务小区的查询；显式不支持的可选查询不妨碍其他可用信息，超时或错帧则停止本轮后续查询和原生补充读取，不立即重试或换通道。忙碌、掉线和扩展执行错误不当作“不支持”而继续排队；故障状态记录实际中断原因。所有客户端只读同一缓存。插件内串行不能代替旧版 QModem 对其他客户端的排队协调，不承诺修复其内部串口竞争。

此传输只用于已审查协议，不因 `send_at` 存在就开放短信发送、删除、锁定或主动搜网。模组不返回 NR 邻区测量时，不会借用服务小区或聚合载波伪装成邻区；主动搜网命令不进入轮询。

### 原生信息兼容回退

没有可用的独立被动解析路径时，原生路径按方法签名读取 `get_current_band(config_section)`，主载波必须与同一配置节的服务小区匹配，不能把错位字段或切网前后的载波混成一组。仅有服务小区时仍展示已确认的载波，但标记额外聚合库存未报告，不宣称已经读取全部 CA。不匹配时拒绝聚合结果，保留服务载波并报告查询错误，而不是猜测改写频点。

QModem LuCI 的手动邻区按钮调用 `get_neighborcell`，不是先启用再读取的开关。已审查的移远、广和通、合宙族可自动执行被动读取；方法名称相同不代表行为相同，含主动搜网等待的实现和返回示例的实现不放入后台轮询。不会调用 `set_neighborcell` 进行扫描，因为它可能锁定或解除锁定。所有本插件的原生采集串行调用，避免上游共用邻区临时文件时相互覆盖；无法代替其他 QModem 客户端的队列协调。

邻区按制式、频点、PCI 校验和去重，剔除服务载波及冲突记录。旧版移远 LTE 邻区的 RSRP／RSRQ 仅在原解释不合法、交换后唯一合法时纠正。未核实的原始编码不冒充 dBm 或 dB。空数组表示本次没有报告可用邻区，不表示附近没有基站，也不证明固件支持 5G 邻区测量。主动全网扫描不混入定时刷新，不为填满界面自动飞行、重启或搜网。

接口输出增加 `radio.carrierState` 与 `radio.neighborState`：包含来源、查询时间、状态及必要的错误码。载波状态可为 `serving-only`；邻区区分 `empty`、`unavailable`、`unsupported` 与 `reported`。邻区能力指经核验的被动读取，不是主动搜网能力。可选查询失败时只在同一采集代际且服务小区身份完全一致时保留上次记录，包括制式、频点、PCI、全局小区标识、TAC 和运营商标识；同频同 PCI 不足以证明身份相同。保留原时间戳，并通过 `queryStatus=error` 与过期状态说明，不能把缓存刷新为新测量。

主信号校验后立即分阶段发布，载波和邻区依次补入，签约速率或温度查询较慢时不会阻塞已读结果的首屏。每次原生调用前后均复核配置绑定，配置改变后不再读取下一项，也不复用旧实例的温度缓存；通道调用失败后暂停本轮剩余补充项。查询中使用 `queryStatus=pending`；沿用历史记录仍保留原时间，不延长其有效期。接口读取只拿缓存，不因网页或小程序刷新次数增加查询。

QModem未提供可用短信服务时可使用安全共享AT；已选数据库后端遇到错误不自动切换来源。插件不会升级QModem、改其短信模式或认领其转发器队列。
