# 网络面板 1.0.4

新增一条命令安装入口，减少APK公钥导入及安装包选择步骤。1.0.3及以前的正式发布内容不覆盖。

- 自动识别apk／opkg及ABI，支持aarch64_cortex-a53与x86_64，未覆盖架构明确拒绝。
- 安装器固定同版下载地址、四种安装包摘要和公钥指纹；APK继续严格验签，不使用安装校验绕过参数。
- 用户确认一次后导入项目公钥、检查依赖并安装，保留原有插件配置；不修改拨号、无线或防火墙配置，不重启路由器。
- 支持在线、离线、仅检查和明确同意的自动化模式。失败不冒报成功，预检失败回收新导入公钥，不静默替换冲突公钥或软件源。
- 安装后核对实际版本、后台服务及连接入口。安装器一次性退出，不增加常驻资源占用。
- Release新增install.sh及摘要清单记录，GitHub Actions加入安装流程安全回归。脚本替身测试与实机安装验收严格区分。

[一键／离线安装教程](INSTALL.zh-CN.md) · [项目说明](https://github.com/SlAlot/wlmb-server/blob/v1.0.4/README.md) · [兼容范围](MODEM-COMPATIBILITY.md)

首次运行安装器仍依赖对官方发布来源的信任。APK公钥为1.0.3已公开的同一把，不换钥、不要求已信任用户再次手动导入。IPK不宣称具有APK逐包签名保证。

本次仅改进安装发布流程，模组协议与功能覆盖未扩大。小程序保持闭源，仅通过插件API接入。
