# 系统接口与固件兼容

WiFi和主机信息优先使用系统提供的UCI、network.wireless、iwinfo及system接口，不识别网页表单，也不把LuCI地址作为WiFi能力证明。驱动是否闭源不作为可用性判断依据；必须核对实际运行状态、频段、信道、频宽和加密能力。

开放网络与加密网络均可读取；编辑已有开放网络时不偷偷加密，也不允许只写一个无效密码。双频合一根据两路实际配置检测；开放网络不要求不存在的密码，开放和加密配置混用时不自动降低安全性。复杂多AP、MLO或无法确认能力的配置保留只读信息，不冒充完全可编辑。

部分无线驱动会重复输出相同字段。仅network.wireless的status回复允许字节完全相同的重复字段，冲突值仍拒绝；登录、授权与其他ubus对象不放宽解码。

QModem存在但未保存use_ubus默认值时，核对at-daemon已经打开的唯一端口及进程归属，再协商共享通道。不会主动打开端口，不修改QModem配置，不改拨号，也不在占用不明时切换到独立模式抢占串口。明确禁用共享、其他客户端占用、服务未就绪或重复配置继续拒绝。

共享和独立模式继续使用同一套模组协议、解析和能力门禁。服务版本不同导致事务、事件或短信写入能力不同时，应报告真实限制；不能只因为识别到型号就保证全部功能。型号回归属于离线协议证据，不等同于逐模组硬件验收。

1.0.7验证中：当前24.10定制固件的缺省共享配置与重复无线字段已由只读探针复现并验证修复；正式发布仍需完成构建、回归与设备验收。
