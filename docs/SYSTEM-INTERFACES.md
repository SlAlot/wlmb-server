# 系统接口与固件兼容

开发代码新增[GL.iNet共享接口适配](GLINET.md)，按真实服务及方法签名发现CPU／USB总线。该适配尚未随正式版发布，写入、事件及全系列实机范围以专项说明为准。

WiFi和主机信息优先使用系统提供的UCI、network.wireless、iwinfo及system接口，不识别网页表单，也不把LuCI地址作为WiFi能力证明。驱动是否闭源不作为可用性判断依据；必须核对实际运行状态、频段、信道、频宽和加密能力。

开放网络与加密网络均可读取；编辑已有开放网络时不偷偷加密，也不允许只写一个无效密码。双频合一根据两路实际配置检测；开放网络不要求不存在的密码，开放和加密配置混用时不自动降低安全性。复杂多AP、MLO或无法确认能力的配置保留只读信息，不冒充完全可编辑。

部分无线驱动会重复输出相同字段。仅network.wireless的status回复允许字节完全相同的重复字段，冲突值仍拒绝；登录、授权与其他ubus对象不放宽解码。

QModem存在但未保存use_ubus默认值时，按at-daemon已经打开的唯一端口识别共享通道，在每次发送前核对进程归属；能力识别与暂时占用分开。不会主动打开端口，不修改QModem配置，不改拨号，也不在占用不明时切换到独立模式抢占串口。明确禁用共享、其他客户端占用、服务未就绪或重复配置继续拒绝发送。暂时忙时仅保留未过期的历史测量，时间戳不更新，到期仍标为过期。

共享和独立模式继续使用同一套模组协议、解析和能力门禁。服务版本不同导致事务、事件或短信写入能力不同时，应报告真实限制；不能只因为识别到型号就保证全部功能。型号回归属于离线协议证据，不等同于逐模组硬件验收。

已观察到旧共享服务在请求服务小区时返回邻区数据。采集器核对已知回复标签和回显，拒绝可识别的跨命令回复；只读主测量最多补查一次，每模组三十秒最多一次，不重复超时命令、不重放写入。错帧被丢弃后只保留未过期历史值和原始采集时间，不把旧值当作新回复。此检查不等于旧服务具有完整事务隔离，未知厂商格式仍交给解析器；对短信写入的租约／队列要求不放宽。

共享服务端口已打开，不代表其他QModem调用路径全部使用共享通道。旧版或定制固件混用直连与共享时，外部访问仍可能阻塞采集。1.0.8不为此新增专用适配，不修改、修补或自动升级QModem，也不接管其拨号和采集任务；本插件只复用现有共享接口并报告真实错误及缓存有效期。此限制不作为模组协议不支持的判断依据，也不承诺所有旧版共享服务均无阻塞。

1.0.8针对当前24.10定制固件的缺省共享配置与重复无线字段修复已有只读探针及离线回归。后台采集每次绑定模组实例；未识别的回复仅记录长度与结构类别，不记录短信或原始回复，不伪装采集成功。其他固件和模组仍需分别验收。
