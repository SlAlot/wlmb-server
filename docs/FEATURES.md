# 1.0 功能与能力边界

网络面板1.0.0提供独立Rust后端与插件WebUI，源码按非商业使用及来源声明许可公开；小程序是独立闭源客户端，其商业授权不在插件内。

| 功能 | 当前实现 | 不能据此承诺 |
| --- | --- | --- |
| 自动识别 | USB／PCIe候选、真实身份、型号／平台／协议选择 | 所有串口都是AT口，或可抢占已有程序 |
| 共享模式 | 核验后的QModem IPC；新短信服务／旧共享AT按接口选择 | 旧接口具有新事件、事务或短信数据库 |
| 独立模式 | 自有Rust通道，打开前核验空闲和身份 | 已被拨号或其他插件占用的串口仍可独占 |
| 信号／载波／邻区 | 多平台解析，有效期和明确缺失字段 | 子载波必有信号，候选频段就是确定频段 |
| 锁频／锁小区 | 模组协议、能力预设、选择／确认／回读 | 保存后立即生效、重启持久、全固件支持 |
| WiFi | 普通LAN AP能力核验，制式／加密／信道／带宽与合一 | MLO、多AP／STA复杂拓扑可任意修改 |
| 设备上网限制 | 自有转发规则，不阻断路由器管理 | 启用加速时所有流量都能准确受控 |
| 流量／速率 | 真实计数差值、接口身份、回绕处理、周期账本 | 启用前历史账单或精准逐IP有线流量 |
| 短信／转发 | 独立已读、确认发送／删除、事件＋10秒兜底、HTTPS | 全模组即时通知、每条最终到达 |
| 温度／签约速率 | 仅展示已核验、未过期的实际返回值 | 所有模组、固件都会提供这些字段 |

无需切卡适配；没有SIM卡槽控制入口。未实现的选网、MLO等能力保持关闭。多模组适配流程相同，但写入和固件差异必须保留门禁。
