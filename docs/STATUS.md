# 1.0.0实际状态

首个公开版本1.0.0仅含OpenWrt插件，闭源商业客户端不在范围。版本、提交和制品以Release中的release.json与SHA256SUMS为准。

自动识别、解析、低频采集、缓存、主机功能、锁定和短信均按能力开放。温度89个身份、锁频81个、锁小区63个、邻区64个、CA71个；所有hardwareAccepted仍为false，表示没有逐型号／固件完整验收记录，不代表没有任何基本读状态验证。

离线回归覆盖协议解析、共享／独立模拟通道、能力门禁、控制回执及前端状态，不据此宣称真实硬件全部通过。

布局采用离线DOM／样式约束检查，不冒充浏览器或微信真机视觉验收。短信实发／转发、锁定生效、WiFi重载、限制上网和长期完整负载仍需硬件验收。
