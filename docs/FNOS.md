# fnOS 适配与验证

## 实现范围

`backend/src/fnos.rs` 复用 `IndependentSource`、采样调度、协议目录和 `NativeService` 的读取能力。仅允许身份验证、健康检查、状态、设置读取、诊断和手动刷新，不开放写入模组的业务接口。

自动发现优先使用明确标为 AT 的唯一端点。RM500U-CNV 的 `2c7c:0900` NCM 组合采用经实机确认的 USB interface 04；按总线和接口身份匹配，不写死 ttyUSB 编号或设备地址。CGMM 被固件拒绝时，以 ATI 核验型号。设备占用检查仍使用原有实现。

网页进程以包用户运行；Rust 采样后端需要查看串口占用及执行本地管理员身份核验，通过权限为 0660 的私有 Unix Socket 服务网页进程。该后端不监听 TCP。凭据仅用于当前验证，不存储、不放入命令参数，不返回密码摘要。

当前未接入飞牛统一网关，使用开发规范允许的独立端口入口与现有管理员验证。应用需要的特权、独立端口及兼容范围均应在商店审核资料中如实说明。

## 原生应用结构

- `manifest`：第三方来源、架构、最低系统版本、稳定应用 ID 和服务端口。
- `config/privilege`：Root 生命周期准备；专用用户运行网页，特权采集隔离。
- `config/resource`：不请求共享目录、系统链接或 Docker 资源。
- `app/ui/config`：管理员专用桌面入口。
- `cmd/main`：启动、状态检查、停止；基于 PID 和命令身份核验，不使用宽泛 pkill。
- 升级与卸载回调先停止应用自身进程。数据保存在系统分配的应用目录。
- `ICON.PNG`、`ICON_256.PNG`、完整生命周期回调和 `wizard/` 由打包准备程序生成。

官方打包工具版本及文件摘要见 `fnos/fnpack.lock.json`。官方文档的 1.2.3 ARM 工具链接当前返回 404；本地 ARM 打包使用官方仍可下载的 1.2.1，CI x86 构建机使用 1.2.3。

## 验证记录

一台 Photonicat 1 / RK3568、fnOS 1.1.31、官方 6.18.18-trim 内核、RM500U-CNV：

- 原生应用目录通过应用中心安装，并能够启动网页与 Rust 后端。
- 实际读取到模组型号、5G SA、频段、RSRP/RSRQ/SINR、服务小区、带宽和模组温度。
- 网页静态资源和管理员验证成功，未认证与伪造系统管理员 Header 的请求被拒绝。
- 离线 DOM 测试复用真实信号组件，覆盖前端挂载与信号参数渲染。
- HTTP 边界测试覆盖会话、跨站请求、路径穿越和任意 AT 写入入口拒绝。

尚未把其他 NAS、全部协议目录型号、长期稳定性或飞牛商店审核列为通过。兼容性信息随进一步实测更新。
