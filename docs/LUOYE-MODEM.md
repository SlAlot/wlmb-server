# 适配落叶小通魔改的 modem

依据作者提供的2026-10-18版接入说明实现；不是只针对某一路由器型号，也不将不同的modem项目视作同一协议。当前实现尚未在原固件上验收，不代表所有厂商和固件均已验证。

## 自动接入

同机检查原组件的`/usr/libexec/modem/at`与`/usr/share/modem/modem_info_cache.sh`，文件须为root所有且不可被普通用户修改。选中后使用专用`luoye-modem-cache`数据源，不再建立QModem、GL.iNet或独立串口后端。即使已有standalone设置，检测到该管理器也不会绕过原事务管理；移除或关闭管理器后需重新确认使用方式。

参数只读`/tmp/modem-info-_dev_modem_at.json`，不调用采集脚本、不访问可能触发采集的LuCI接口。缓存缺失或不合法只报告不可用；若原组件在没有浏览器访问时停止发布，需要由原组件解决，不通过网络面板补采集。

全程不依赖路由器管理IP或LuCI端口。网络面板对外仍使用设备实际LAN地址与1117端口，小程序继续使用原登录和状态API，无需新增认证流程。

## 参数与时间

读取LTE、NR SA和NSA的服务测量、运营商标识、温度和载波列。NSA按LTE锚点与NR分别保留，载波保留PCC／SCC角色，缺失的上行信息和逐载波信号不补造。保留PCI、SINR、CQI和MCS的合法零值，CSI扩展只属于对应服务测量，不复制给每个载波。

AMBR有明确单位时换算到Kbps；无单位值在尚未确认原脚本厂商编码时留空。CQI不冒充QCI。无法唯一解释的多分支信号、HTML和冲突字段不截取首个数字。

直接读取同一文件描述符的JSON和元数据，拒绝符号链接、非普通文件、非root发布或可被其他用户修改的缓存；限制最大256KiB。以主机启动ID和逻辑端点元数据隔离生命周期，缓存必须在当前启动与端点创建后发布，才可用于新鲜状态和邻区查询。这是可取得的本机隔离信息，不等同于原组件提供了模组generation；同端点内部重置但不更新任何身份元数据仍需原组件补充代次契约。

`sourcePublishedAtMs`为来源文件mtime，`receivedAtMs`为网络面板读取时间。兼容字段`observedAtMs`沿用来源发布时间，并明确标记`observationTimeBasis=source-file-publication`、`sourceObservationTimeUnknown=true`，不宣称每项测量的原始观测时刻已知。超过15秒、时间在未来、跨启动或无法绑定端点时标记stale，重复读取不刷新原时间。无时区的`update_time`不直接解释为UTC。

## 邻区

通过原有`/usr/libexec/modem/at --json`工具执行，使用参数数组和stdin，不拼接shell，不打开串口。每次仅一条已识别型号的固定被动邻区查询，profile必须与发布的厂商及本项目型号目录匹配。未知型号、厂商冲突、过期缓存和身份未确认时不发查询；不包含主动搜网、锁定、短信或任意AT透传。

每个后台任务共用一次结果，正常至少十秒查询一次；先发布缓存主信号，再补邻区。读取前后核对本机实例与缓存服务小区身份，变化时丢弃结果。结果必须满足退出状态、JSON错误字段、独立终止行及已有解析器；只有OK但没有可解析邻区时报告未报告，不自动断言附近没有邻区。

忙碌至少退避30秒，明确拒绝或没有报告至少退避5分钟。工具超时、错帧及未知结果不自动重试，当前实例暂停自动邻区，API标记`automaticRetryPaused=true`。这是因为原组件已排队任务可能在客户端退出后继续执行；重启网络面板不保证原任务已取消，排查时应先确认原事务服务已经恢复。现有工具内部可能采用同锁的直接执行路径，此行为由原组件管理，不宣称具有owner-required保证。

如需关闭此来源的邻区，在UCI设置`network_panel.main.luoye_neighbors=0`并重新加载网络面板服务；它不影响原组件参数发布。默认开启已适配的只读邻区能力，是否能返回NR邻区仍由模组固件决定。

## 操作边界与验收

此数据源不开放AT控制台、锁频、锁小区、短信收发删除或短信转发。所有普通query入口在后端拒绝，不能仅通过界面显示控制。WiFi、流量和在线设备仍走已有系统能力判断。

已增加合成样本、缓存过期、CA列对齐、NSA分组、身份变化、未知结果不重发、只读请求白名单、控制拒绝及采样器接入回归。Linux文件权限、真实发布频率、原事务工具profile、超时行为和各型号邻区仍需原固件验收。只根据源码和离线测试不能宣称完成真机适配。
