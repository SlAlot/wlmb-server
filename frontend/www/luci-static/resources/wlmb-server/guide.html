连接只需三步

同一局域网
  1. 01

    确认插件运行

    在面板「设置」中确认服务正在运行，模组已识别。

  2. 02

    手机连接路由器 WiFi

    在微信中搜索并打开「网络面板助手」，设备厂商选择 openwrt。

  3. 03

    填写管理地址与账号

    使用你的管理地址，端口为 1117。填写 root 与当前 OpenWrt 后台密码后连接。

本机参考连接地址你的管理地址:1117

请使用路由器实际管理地址，务必保留 :1117；不一定是 192.168.1.1。

插件免费使用；小程序是独立客户端，授权单独管理。只在可信局域网使用，不要将 1117 端口开放到公网。

短信与转发，各自开关

查看短信

先开启短信收取

在插件「短信」页开启收取，再读取收件箱。小程序可在「短信」中查看；没有短信时，空列表是正常状态。

PushPlus 转发

填入 Token，再开启转发

小程序入口：设置 → 短信转发。插件入口：短信 → 短信转发。保存 PushPlus Token 并开启后，只转发新收到的短信，不补发首次启用前的历史短信。

新短信事件到达时优先处理；无事件时默认每 10 秒检查，通道忙碌会退避，不保证固定送达时间。关闭转发会停止转发任务；独立收取开关不受影响，两项都关闭时不运行后台收取任务。

Token 不在页面回显。启用转发后，短信正文将通过 HTTPS 交给 PushPlus；请确认自己的 Token 与隐私设置。

常见问题
连接不上小程序怎么办？

先核对管理地址与 :1117，再检查手机是否连到同一路由器、微信是否允许本地网络访问。访客 WiFi 可能隔离局域网。仍无法连接时，到插件设置查看运行状态与「脱敏诊断」。

信号、频段或邻区显示「—」？

功能按模组实际能力开放。「—」表示本次未读取，不代表信号为零。子载波可能只报告频段与带宽，不报告信号参数。请结合通道状态与诊断信息判断，不要反复发送查询。

锁频与锁小区，怎样操作更安全？

先读取配置，再选频段或从服务小区、邻区加入锁定目标，检查并保存。保存配置不等于已经驻留到目标；请查看后续反馈。插件不自动切飞行模式、重拨或重启，供网设备请谨慎操作。解除锁定也需确认。

AT 控制台有什么注意事项？

优先使用面板已有功能。AT 默认只读，配置型指令需开放权限并逐次确认；不要粘贴来源不明的命令。共享模式使用现有通道，独立模式核验空闲接口，不抢占串口或接管拨号。

流量统计与其他控制有什么限制？

流量按插件记录累计，与运营商账单可能不同；限额停网仅在已核验的防火墙环境开放。WiFi 修改可能短暂断开连接，短信发送可能收费、删除不可撤销。写操作结果不明时，先刷新状态，不要重复提交。

开启后仍没有新短信或转发？

没有收到短信时，列表为空是正常的。确认收取／转发开关、Token 和设备联网状态，再检查插件日志中的具体原因。不同模组及共享通道能力不同，不要以空列表直接判断功能不支持。
